# 项目设计

## env设计

**当我们写环境的代码时，我们要将视角变为环境，去观察agent的行为，这样才可以更好的理解为什么将环境拆分出来**

env为强化学习所需要的环境，对于本项目，我们可以将环境拆分为，初始化环境init、重置环境reset(环境被agent影响)、agent受到环境的影响step、agent的位置和宝箱获取情况state、等一些功能性函数。

1. init : 首先是地图信息，随之我们可以想到地图信息引申出来的地图大小(也可以想到获取地图信息的功能函数获取某个东西的位置)，地图的最大步数限制，地图中的行为(上下左右),以上为静态信息，还有动态信息，每次训练我们需要归零的，我们用reset来表示
2. reset : reset中我们可以设置一些信息,可变地图、agent步数、游戏是否结束、(宝箱、agent、终点的位置)、获得的宝箱位置(用集合表示，如果获得，将位置存入set中),我们这里返回值state,符合接口标准(这里不用agent获取state是因为agent不需要关心env的内部，低耦合)
3. get_state : 换句话说其实也是state函数，这里设计state值为agent位置和当前获得宝箱情况，因为在同一个位置获得宝箱和没获得宝箱的情况不一样，所以宝箱信息是一定要传入的q值
4. step ：最重要的，我们设计他的参数为action，由agent决定，返回值要符合标准(state,reward,done,info),其内部还要改变env的动态信息，如steps...等,
5. render : 打印当前状态，方便调试
6. 剩余的部分为一些功能辅助函数了
